## 添加到 SideStore

在装有 SideStore 的 iPhone 或 iPad 上打开 [shmarket 主页](https://sushuheng.github.io/ipa-apps/)，点 **在 SideStore 中添加**。也可以在 SideStore 的 **Sources → ＋** 中粘贴以下地址。

```text
https://sushuheng.github.io/ipa-apps/source.json
```
